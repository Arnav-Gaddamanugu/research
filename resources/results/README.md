# Raw and Simulated/Processed Data

These links go to the files for the complete raw data that the solver outputs when processing, the base configurations for each of the linkages and their nodes, and the aggregated data that combines the configurations with the raw data into one dataset. 

- To get this data, download the aggregated_results.csv, base_linkage_configs.csv, and raw_data.csv files. There is no need to place these in any specific folder, as they are the outputs of the system and not input data.

# Simulation and Motion Modules

These links go to the simulation module in Python, which the truss solver uses to generate the full range of motion. The other module is a general processing module, which is needed to process the complex linkages.

- To use this dataset, download the sim.py and utils.py files and place them in the same folder as the Truss Generator file. The program will automatically process the data through the modules.
